# Local AI Assistant

**Локальный русскоязычный ассистент для управления компьютером с помощью текстовых команд.**

<sub>Текущая версия: **1.4.3** · Платформы: **Windows 10/11 и Linux (предварительная поддержка)** · Язык проекта: **Rust**</sub>

> Проект находится в разработке. Название «AI Assistant» описывает цель проекта, но в версии 1.5.0-alpha.1 языковая модель ещё не подключена: команды распознаются локальным кодом по набору правил и шаблонов. Ассистент не отправляет введённый текст в облачный ИИ-сервис
> Если у вас работает переводчик на браузере, пожалуйста, выключите ее. Он ломает не только слова, но и пасхалку

## Что это за проект

Local AI Assistant — приложение, которое позволяет выполнять распространённые действия на ко**м**пьютере, формулируя их обычным русским языком. Вместо ручного поиска настроек пользователь вводит команду в ассистент. Windows-версия имеет графическое окно; Linux-версия на текущем этапе запускается в терминале.

Общая логика команд и файловых операций написана на Rust. Платформенные действ**и**я разделены: Windows использует Win32 API и PowerShell, Linux — стандартные системные интерфейсы и утилиты (`/proc`, `/sys`, `pactl`, `brightnessctl`, `nmcli`). В Linux-сборке пока доступен консольный режим; Windows сохраняет графическую оболочку и системный трей.

### Для кого проект

- Для пользователей Windows, которым удобнее давать короткие текстовые команды, чем искать наст**р**ойки вручную.
- Для тех, кто хочет автоматизировать повседневные действия с файлами, звуком, экраном и сетью.
- Для начинающих разработчиков, которым интересен практический проект на Rust с Win32 API, обработкой текста, процессами и потоками.
- Для тех, кто хочет изучать устройство локального помощника и в дальнейшем расширять его собственными командами.

## Что умеет сейчас

### Файлы и папки

- Создавать папки и файлы.
- Записывать текст в создаваемый файл.
- Переименовывать и перемещать файлы и катал**о**ги.
- Удалять отдельные файлы и папки.
- Очищать содержимое папки, не удаляя саму папку.
- Использовать рабочий стол как место назначения по умолчанию для относительных путей.
- Понимать несколько дейст**в**ий в одной фразе, последовательные команды и ссылки на ранее упомянутую папку — например, «в неё» или «в ней».

### Управление Windows

- Смотреть текущую громкость.
- Устанавливать громкость в процент**а**х и менять её относительно текущего значения.
- Включать и выключать звук.
- Смотреть текущую **я**ркость экрана, устанавливать значение и менять его относительно текущего уровня.

### Сеть

- Проверять состояние сетевых подключений.
- Показывать список сетевых адаптеров, их состояние, скорость и MAC-адрес.
- Показывать доступные сведения о IP-адресе, шлюзе и DNS.
- Включать и отключать выбранный сетевой адаптер по его и*м*ени.

Для изменения состояния сетевого *а*даптера могут потребоваться права администратора. Перед отключением адаптера ассистент запрашивает подтверждение, поскольку это действие может разорвать подключение к Интернету.

### Информация о компьютере

Ассистент может вывести имя компьютера, производителя и модель устройства, версию Windows, процессор, количество ядер и логических потоков, видеокарту, объём оперативной памяти и состояние батареи (если она обнаружена).

### Окно, трей и горячая клавиша

- Нативное окно Windows с историей сообщений, полем ввода и кнопкой отправки.
- Отправка команды клавишей **Enter**.
- Значок в системной области уведомлений (трей).
- Закрытие или сворачивание окна скрывает его в трей, если Windows смогла создать значок.
- Контекстное меню значка позволяет снова открыть окно или полностью завершить работу.
- Глобальная горячая клавиша открывает окно, пока процесс ассистента запущен. По умолчанию используется `Ctrl+Alt+Space`; сочетание можно изменить командой.

### Удаление приложения

Команда «самоуничтожение» запускает отдельный сценарий подтверждения. Для продолжения нужно ввести точную фразу `УДАЛИТЬ АССИСТЕНТА`.

Приложение удаляет собственный EXE. Полностью удалить переносимую папку `dist` оно может только при совпадении специального маркера, который создаёт скрипт сборки. Также удаляется файл настройки горячей клавиши. Исходники проекта и документы пользователя не затрагиваются.

## Поддержка Linux (предварительная)

Версия 1.5.0-alpha.1 начинает перенос общей логики на Linux. Уже доступны:

- консольный режим запуска;
- общая обработка русскоязычных команд и файловые операции;
- сведения о системе через procfs/sysfs;
- управление громкостью через `pactl` (PulseAudio или PipeWire с `pipewire-pulse`);
- управление яркостью через `brightnessctl` (если устройство и права доступа это позволяют);
- просмотр сетевых устройств и управление ими через NetworkManager `nmcli`.

Пока **не реализованы** Linux GUI, глобальные горячие клавиши и самоудаление. Это альфа-версия: наличие системной команды не гарантирует доступ к соответствующему устройству в каждой среде. Подробнее — в [`LINUX_TESTING.md`](LINUX_TESTING.md).

### Быстрый запуск Linux

```bash
./build_linux.sh
./dist/linux/local_ai_assistant
```

`build_linux.sh` запускает тесты, собирает release-бинарник и копирует его в `dist/linux/`.

## Примеры команд

Команды можно вводить в нижнее поле окна. Названия файлов и папок лучше брать в кавычки, особенно если в них есть союз «и».

| Что сделать | Пример команды |
|---|---|
| Создать папку | `Создай папку «Учёба»` |
| Создать файл в папке | `Сделай файл «Конспект» в папке «Учёба»` |
| Использовать последнюю папку | `Создай папку «Проекты» и в неё сделай файл «План»` |
| Выполнить два действия по очереди | `Создай папку «Важное», а потом сделай файл «Счёт» на рабочем столе` |
| Удалить файл | `Удали файл «Черновик»` |
| Установить громкость | `Установи громкость на 35%` |
| Изменить громкость | `Сделай звук громче` / `Сделай звук тише на 5%` |
| Выключить звук | `Выключи звук` |
| Установить яркость | `Установи яркость 70%` |
| Узнать сведения о ПК | `Покажи характеристики компьютера` |
| Посмотреть адаптеры | `Покажи сетевые адаптеры` |
| Проверить сеть | `Какая сеть?` |
| Посмотреть горячую клавишу | `Какая гор. клавиша?` |
| Изменить горячую клавишу | `Поменяй гор. клавиши`, затем ввести `Ctrl+Alt+K` |

Для удаления приложения сначала введи `самоуничтожение`, а после запроса подтверждения — `УДАЛИТЬ АССИСТЕНТА`. Чтобы отказаться, напиши `отмена`.

## Как устроен проект

```text
Local-AI-Assistant/
├── Cargo.toml                 # Пакет Rust и зависимости
├── build_windows.bat          # Тестирование и сборка Windows EXE
├── build_linux.sh             # Тестирование и сборка Linux-бинарника
├── LINUX_TESTING.md           # Проверка Linux через WSL2 и виртуальную ма*ш*ину
├── .github/workflows/ci.yml   # CI для Ubuntu и Windows
├── README.md                  # Оп*и*сание проекта для GitHub
├── CHANGELOG.md               # История изменений версий
├── RULE_OF_READING.md         # Правила разбора составных русских команд
├── .cargo/                    # Настройки Cargo
├── .vscode/                   # Настройки задач VS Code
└── src/
    ├── main.rs                # Точка входа и маршрутизация команд
    ├── gui.rs                 # Окно Win32, трей, ввод и связь с worker
    ├── parser.rs              # Разбор русскоязыч*н*ых файловых команд
    ├── file_manager.rs        # Создание, перемещение и удаление файлов
    ├── system_control.rs      # Громкость и яркость: Windows API / pactl / brightnessctl
    ├── network_control.rs     # Сеть: PowerShell / NetworkManager nmcli
    ├── pc_info.rs             # Сведения о ПК: CIM/WMI / procfs/sysfs
    ├── hotkey.rs              # Разбор, хранение и регистрация сочетаний клавиш
    └── self_uninstall.rs      # Подтвержд*а*емое удаление приложения
```

### Как проходит команда

В Windows: пользователь вводит текст в GUI, окно передаёт команду рабочему процессу, модуль выполняет действие, а GUI показывает ответ. В Linux альфа-версия пока принимает ввод непосредственно в терминале и использует тот же командный разбор с Linux-реализациями системных операций.

Файловый разбор учитывает кавычки, порядок действий и контекст последней созданной папки. Подробные правила описаны в [`RULE_OF_READING.md`](RULE_OF_READING.md).

## Сборка и запуск

### Требования для разработки

- Windows 10 или Windows 11.
- [Rust stable](https://www.rust-lang.org/tools/install) и Cargo.
- Для нативной Windows-сборки — MSVC toolchain (обычно устанавливается вместе с Visual Studio Build Tools).
- Интернет при первой сборке может потребоваться Cargo для загрузки зависимостей.
- VS Code рекомендуется, но не является обязательным.

### Linux (альфа-поддержка)

Для тестирования подойдёт Ubuntu LTS или совместимый дистрибутив. Нужны Rust stable и Cargo. Для системных функций могут потребоваться `pactl`, `brightnessctl`, NetworkManager (`nmcli`) и `pciutils` (`lspci`). Эти инструменты необязательны для запуска парсера и файловых команд.

Подробный сценарий установки WSL2/Ubuntu VM находится в [`LINUX_TESTING.md`](LINUX_TESTING.md).

### Запуск из исходников

1. Скачай репозиторий или распакуй архив проекта.
2. Открой в VS Code именно корневую папку проекта — ту, где находится `Cargo.toml`.
3. Открой встроенный терминал в этой папке.
4. Выполни тесты:

   ```bash
   cargo test
   ```

5. Для запуска в режиме разработки выполни:

   ```bash
   cargo run
   ```

### Создание переносимой сборки

В корневой папке проекта запусти:

```text
build_windows.bat
```

Скрипт последовательно запускает тесты, собирает Release-версию и копирует EXE в папку `dist`. В ней также создаются краткая инструкция и маркер, используемый безопасным сценарием удаления.

Для переноса на другой Windows-компьютер скопируй **всю папку `dist`**, а не только EXE. На целевом компьютере не требуются VS Code и Rust.

## Важные ограничения и безопасность

- **Это пока не полноценный диалоговый ИИ.** В версии 1.5.0-alpha.1 нет подключённой нейросети, распознавания речи или произвольного понимания любой фразы. Поддерживаются формулировки, предусмотренные правилами текущего парсера.
- **Удаление файлов окончательное.** Файловый модуль использует прямые операции файловой системы, а не Корзину Windows. Команда очистки удаляет содержимое выбранной папки. Проверяй имена и расположение перед подтверждением действий.
- **Создание файла может перезаписать существующий файл** с тем же путём, поскольку используется запись через `fs::write`.
- **Относительные пути относятся к рабочему столу.** Для другого места указывай полный путь, например `D:\Документы\Проекты`.
- **Яркость зависит от оборудования.** Управление доступно только для мониторов, которые Windows предоставляет через соответствующий WMI-интерфейс. Некоторые внешние мониторы не поддерживают такой способ управления.
- **Сетевые изменения требуют привилегий.** Для включения/отключения адаптеров может понадобиться запуск от имени администратора.
- **Горячая клавиша не запускает закрытое приложение.** Она возвращает окно только пока Local AI Assistant работает в фоне. Если сочетание занято другой программой, выбери другое.
- **Графический интерфейс рассчитан на Windows.** Для других платформ в проекте оставлены только отдельные заглушки/возможности сборки и тестирования парсера.

## Планы развития

Это направления дальнейшей работы, а не функции текущей версии:

- Улучшить понимание свободных русскоязычных формулировок и контекста диалога.
- Добавить больше команд для управления Windows и приложениями.
- Развить настройки интерфейса и сделать GUI удобнее.
- Продумать подключаемую архитектуру модулей, чтобы новые действия можно было добавлять независимо.
- Исследовать возможность опциональной интеграции локальной языковой модели. Такая интеграция должна оставаться отдельной от базового локального механизма команд.
- Расширить автоматические тесты и документацию для новых функций.

## Участие в проекте

Предложения, сообщения об ошибках и идеи новых команд приветствуются. При сообщении об ошибке полезно приложить:

- версию проекта и версию Windows;
- точную команду, которую ты ввёл;
